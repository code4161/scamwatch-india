# Demo video

The recorded video is [docs/demo.mp4](demo.mp4) (1 minute 55 seconds, 1280x720). It was captured from the deployed site in headless Chrome on 2026-10-14, narrated with the macOS Aman (English, India) voice, with the narration burned in as captions. Shot 6 is a real confirmation: transaction 0x09e813f6a50df0f7f1721929bb21cc29f2d69857af1249a037f255ec1430d1b5, which created confirmation 0x37147b9976b65cc7c7ade253169390533a91d1a6a87645e6234afc9a50b4fee6.

| # | on screen | narration |
|---|---|---|
| 1 | home page, then the live feed | A stranger adds your father to a stock tips WhatsApp group, and the group sends him a trading app. Before he pays, he can paste the link here. ScamWatch India is a public registry of investment scams that target people in India. Everything you see is synthetic demo data on the Arkiv Tiramisu testnet. |
| 2 | type pay.secure-login-tradebrokr.example, press Check, open "Exact query sent to Arkiv" | This link finds a report filed against its parent domain. The page has no backend. The query you see goes from the browser straight to Arkiv's public RPC, so if our site went away, anyone could still run it. |
| 3 | type safe-and-unknown.example, press Check | No report does not mean safe. The app points people to SEBI's registers of advisers, analysts and brokers, and the footer gives the 1930 cyber crime helpline. |
| 4 | the doubleyourmoney-in30days.example report: signed by, owner, expiry, flags, then the confirmations | Every report is signed. The chain records which wallet created it, and that is what the Attested badge trusts, never a field someone can type. Reports are read only once filed, and anyone may extend them. An unconfirmed report expires after seven days. Each confirmation from another wallet adds thirty. |
| 5 | Browse: severity 2 to 5, query open, Load more | Severity and filing time are numeric attributes, so Browse runs real range queries, and the results page with a cursor. |
| 6 | home feed scrolled to com.example.niftyprotrader; terminal inset runs npx tsx cli/scamwatch.ts confirm --report 0x9e49d1b0fcf65c3d519c06320fe31c5ab714515e4f97d309c894b3bdde8f63a1 --as confirmer2; the card's countdown moves from 66 to 96 days and its count from 2 to 3; then the live log | Now a second wallet confirms a report from the command line. One batch creates the confirmation and extends the report. The feed is subscribed over a WebSocket, so the confirmation shows up here, and the countdown moves out by thirty days, with no reload. |
| 7 | the Attested page, then the curator's transactions on the Arkiv explorer | Trusted reviewers are listed on chain by the curator, as ninety day leases. The app refuses phone numbers, UPI IDs and email addresses before anything is signed. Every entity can be checked on the Arkiv explorer, and the code is open source under MIT. |
